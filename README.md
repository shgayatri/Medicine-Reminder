# 💊 Medicine Reminder Web App

## 📌 Overview
This is a simple web-based Medicine Reminder application that helps users add and manage their daily medicine schedule. It provides an easy-to-use interface for setting reminders.

---

## 🚀 Features
- ➕ Add medicine name
- ⏰ Set reminder time
- 📝 Add description (optional)
- 🎨 Clean and user-friendly UI
- 📱 Responsive design

---

## 🛠 Tech Stack
- HTML
- CSS
- JavaScript

---

## ▶️ How to Run
1. Clone the repository:
   git clone https://github.com/shgayatri/Medicine-Reminder.git

2. Open the project folder

3. Run:
   Open `index.html` in your browser
